# 把节目单挂到自己的直播源上（M3U 对接）

> 本文回答一个具体问题：**我自己抓的 m3u 直播源，能不能用这份 EPG？**
> 结论：能，但不是「订阅同一个地址就行」——两边的频道 id 体系不同，必须生成一份 id 改写版。
> 所有数字都是对 [XinMan939/iptv-api](https://github.com/XinMan939/iptv-api) 的 `output/result.m3u` 实测得出的。

## 一、为什么直接用 epg.xml 挂不上

| | 我们（epg.xml） | 你的 m3u（result.m3u） |
|---|---|---|
| channel id 写法 | `CCTV1.cn` `ZhejiangSatelliteTV.cn` `Jade.hk`（iptv-org 规范） | `CCTV1` `浙江卫视` `TVB翡翠`（裸名） |
| 名字写法 | `CCTV-1 综合` | `CCTV1` / `CCTV-1` / `CCTV-1 HD` 混排 |

播放器挂节目单靠 `tvg-id` 与 `<channel id>` **字符串相等**。两边一个都不相等，所以直接订阅 = 一个台都挂不上。这不是内容问题，是 id 体系问题。

## 二、解法：一条命令生成 id 改写版

```bash
# 1) 对齐：告诉它你的 m3u 在哪（本地路径或 URL 都行）
node src/index.mjs m3u https://raw.githubusercontent.com/XinMan939/iptv-api/master/output/result.m3u

# 2) 构建：会额外产出 output/epg-m3u.xml
node src/index.mjs build
```

第 1 步产出 `channels/m3u-map.json`（映射表，建议入库），第 2 步产出的 `output/epg-m3u.xml` 里 **channel id 已经是你的 m3u 侧写法**：

```xml
<channel id="CCTV1">          <!-- 不是 CCTV1.cn -->
  <display-name lang="zh">CCTV-1 综合</display-name>
  <display-name lang="zh">CCTV1</display-name>
```

第 3 步：播放器里 **EPG 订阅填 `epg-m3u.xml.gz`，直播源填你的 m3u**，节目单自动挂上。除此之外不需要改任何一侧，也不需要把两个项目合并。

## 三、匹配机制：五级，宁可漏不可串台

| 级别 | 规则 | 实测命中 |
|---|---|---|
| ① manual | `m3u-map.json` 里手工写死的映射，优先级最高 | 0 |
| ② id-exact | 两边 id 完全相等 | 0 |
| ③ id-stripped | 我们的 id 去掉 `.cn/.hk/.tw/.mo` 后相等 | 21 |
| ④ name-unique | 名字/别名归一化后相等，且该名字在 m3u 里唯一 | 69 |
| ⑤ name-loose | 繁→简 + 去台标前缀（TVB/CCTV）+ 去「卫视/电视/频道/台」，且**两侧都唯一** | 5 |

第 ⑤ 级是这一轮新加的，专治这批同台异名：

| 我们 | m3u | 说明 |
|---|---|---|
| 翡翠台 | TVB翡翠 | 繁简 + TVB 前缀 + 尾部「台」 |
| 明珠台 | TVB明珠 | 同上 |
| 無綫新聞台 | TVB无线新闻 | 繁简（綫→线）+ 前缀 + 尾部「台」 |
| 鳳凰衛視香港台 | 凤凰香港 | 繁简 + 去「卫视」+ 尾部「台」 |
| 三立台灣台 | 三立台湾 | 繁简 + 尾部「台」 |

**为什么必须两侧都唯一**：宽松规则会塌名字（湖南卫视/湖南国际都塌成「湖南」）。只要某一侧塌出歧义，就直接放弃匹配、留给人工，绝不猜。

## 四、实测结果

你的 `result.m3u`：4376 条节目源，去重 **318 个 tvg-id**。

- 我们 114 个频道里，**95 个能对上**（83%），其中 88 个实际有节目
- 反向覆盖你的 318 个 tvg-id 的 **95 个（29.9%）**

## 六、补频道能补到多少

拿 51zmt（e1/e2）和 epg.pw（CN/HK/TW）的频道名，按同一套宽松规则去撞你那 223 个缺口：

- **能撞上 148 个**（占缺口 66%），补进清单后总覆盖 **243 / 318 = 76.4%**
- 其中 **71 个能拿到 ≥5 天**节目，其余多为 1~2 天（epg.pw 的地方台/付费台只给当天，属源的限制）
- 剩下 **75 个全网无 EPG**：咪咕赛事 17 个全无、台湾约 24 个、广东 8 个、港澳 21 个（多为 myTV SUPER / Now TV 付费频道）

## 八、两个踩过的坑

**坑：时间轴对齐不可靠。** 试过用节目开始时间对齐（比如延边卫视朝鲜语标题 → 51zmt 中文标题），TOL=15 分钟能对出 12 组，但 `일기예보`（天气预报）被错配成「看神州」——两边时间轴本身有错位。已放弃，改走人工 `titleMap`（见 `channels/overrides.json`）。

**坑：繁简不统一会产生大量假性缺口。** 我们有 7 个频道一开始看着「你那边没有」，其实是 `鳳凰衛視香港台` vs `凤凰香港` 这种。修 `normName()` 接 `toSimplified()` 后，匹配数 90 → 95。
